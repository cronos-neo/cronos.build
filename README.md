## Vue d'ensemble

Depot source du portfolio de Cronos, developpeur Full-Stack & Systemes.

Le site est developpe avec Svelte 5 et TypeScript :
- Interface reactive legere sous Svelte 5.
- Polices auto-hebergees au format WOFF2 local.
- Terminal integre pour la navigation rapide (`projects`, `skills`, `contact`, `cv`).
- Support bilingue Francais / Anglais.

## Developpement

### Prerequis
- Node.js 20+ ou Bun

```bash
# Installation des dependances
bun install # ou npm install

# Serveur de developpement
bun run dev

# Verification des types
bun run check

# Build de production
bun run build
```
